# Pimp My Grade

Cette feature personnalise les pseudonymes de la shoutbox selon le grade
Tr4ker détecté par leur couleur native. Les réglages V3 sont conservés :

- `tm_t4_grade_pseudonym_colors`
- `tm_t4_grade_pseudonym_effects`

Le catalogue de grades et la présentation des badges sont fournis par
`src/core/grades.js`, afin que les autres features (dont la carte profil)
emploient les mêmes libellés et couleurs.
